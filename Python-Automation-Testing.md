# Python Selenium Automation Testing

## Project Overview

This project demonstrates beginner-level test automation using Python and Selenium WebDriver.

The automated test validates the login functionality of a sample web application.

## Technologies Used

- Python
- Selenium WebDriver
- Google Chrome
- GitHub

## Test Scenario

Verify that a user can successfully log into the application using valid credentials.

## Automated Test Steps

1. Launch the Chrome browser.
2. Navigate to the login page.
3. Locate the username field.
4. Enter a valid username.
5. Locate the password field.
6. Enter a valid password.
7. Click the Login button.
8. Verify that the successful login message is displayed.
9. Print the test result.
10. Close the browser.

## Expected Result

The user should successfully log into the secure area and see a confirmation message.
